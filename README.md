# Image-Classification-of-CIFAR-10-dataset
Implementation of a CNN model using TensorFlow or PyTorch to classify images from the CIFAR-10 dataset into 10 different categories

-> Implement a CNN model using TensorFlow or PyTorch to classify images from the
CIFAR-10 dataset into 10 different categories (e.g., airplane, automobile, bird, etc.).
• Requirements: 
Preprocess the images, define and train the CNN model, evaluate the
model's performance using accuracy metrics, and visualize the model's predictions.
• Metrics: Accuracy
• Loss Function: Cross-Entropy Loss
